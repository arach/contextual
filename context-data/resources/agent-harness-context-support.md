## Creation Shape

An agent-assisted context should produce:

1. Resource selections with keep, compress, refresh, or drop actions.
2. Tight context parts with source ids and truth labels.
3. Briefing, working-set, and deep-pack profiles.
4. A test-drive record before launch.
5. A session thread whose fixed modules come from the compiled profile.
